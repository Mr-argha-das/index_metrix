Replacing a key pauses delivery and requires a fresh ownership check. Do not upload keys in chat or commit them to Git. File permissions protect local storage; use encrypted disks/backups on your server.

Google setup checklist

  1. Set PUBLIC_BASE_URL=https://v1.indexmetrix.com (or your actual owned origin) on the server.
  2. In Google Cloud, enable Indexing API and Search Console API in the service-account project.
  3. Verify ownership of your site in Search Console, then add the JSON file's client_email as a delegated owner. Full-user access alone is insufficient for this integration.
  4. Obtain the required API approval/quota. Google's initial testing quota is 200 publish requests per day per project; other tools sharing the project also consume it.
  5. Upload the key, verify ownership and enable delivery here. Then publish a real vacancy.

Scopes: indexing for notifications; webmasters.readonly to verify ownership. Ownership is checked again before delivery.

Automatic delivery: persistent deduplicated queue, bounded retries for temporary failures, and local rate limits. Demos, arbitrary PDFs and normal articles do not qualify.

ACCEPTED ≠ INDEXED. This UI records notification delivery, not Google's crawl or index state. No private endpoint, CAPTCHA bypass or Search Console UI automation is used.
